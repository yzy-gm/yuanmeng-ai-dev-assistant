## 大数据性能

- 子进程生成并解析匿名 100,000 节点 `CustomUIData2.lua`；解析/索引计时和 exact-name 查询 P95 独立采样。
- 本次定向运行：parse/index `<= 5 s` 通过，exact-search P95 `< 100 ms` 通过。
- 子进程在建好索引后显式释放不再需要的原始文本和 Lua AST、执行 GC，并无条件输出结构化性能数值；测试保持产品默认 Node 参数，没有加入 VSCode Extension Host 未使用的内存优化开关。
- 六次连续定向运行中，RSS 为 491–547 MB；五次低于 `512 MiB`（`536,870,912` bytes），一次为 `547,139,584` bytes 并使硬门失败。解析/索引 1.44–1.94 秒、exact-search P95 6.16–17.98 ms 均稳定通过。由于 RSS 不能稳定满足阈值，测试恢复明确的 `PERFORMANCE_GATE_UNVERIFIED` 和低于 768 MiB 的诊断上限；本机 RSS 门仍不是 PASS。
- 隔离诊断曾验证 `--optimize-for-size` 可显著降低 RSS，但该参数不属于产品实际宿主契约，没有被塞进测试冒充通过。
