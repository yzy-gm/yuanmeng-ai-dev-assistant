# 编辑器验收清单

每项必须记录证据等级。自动化测试只能记为 `UNIT_E2E`/`EXTENSION_HOST`，不能替代 `OFFICIAL_EDITOR_SINGLE` 或多人实测。

## A. 安装与共存

- [ ] 从市场或已检查的公开 VSIX 安装。
- [ ] VS Code 重载后显示作者“不见星光”和“场景元件与编组”视图。
- [ ] 官方元梦 Lua 插件仍可启用、联动、更新工程和合成脚本。
- [ ] 卸载本助手不会修改或卸载官方插件。

## B. 场景读取

- [ ] 在匿名测试地图分别绑定 Manual/Auto/Raw 中至少一个来源。
- [ ] 首次读取数量与编辑器可见测试对象一致。
- [ ] 新增一个元件并保存后自动出现。
- [ ] 删除一个元件并保存后从快照消失，台账记录变为 `suspected-change`。
- [ ] 移动、旋转、缩放一个元件，`scene-diff` 分别显示对应变化。
- [ ] 创建/解散编组、增删成员，编组视图和 `group-members` 一致。
- [ ] v6 字段检查器显示父/子编组、编组变换、数值属性、实例/根信号、图层名、版本文本和实例索引；候选元数据仍带低置信证据。
- [ ] 类型覆盖率的已识别/未知数量与当前快照一致，未知类型不会自动套用 Element API。
- [ ] 特殊未校准分支显示为 unsupported，不静默漏掉。

## C. ID 与属性

- [ ] 场景实例 ID、类型 ID 可复制，并自动生成 pending/unspecified 台账记录。
- [ ] 同类型多个实例查询返回 ambiguous，不擅自选择。
- [ ] 运行测量探针，日志含类型、变换、尺寸、中心、可见、物理、碰撞、抓取、parent 和 childCount。
- [ ] 使用一个匿名自定义属性名运行属性定位，日志 `YMAI_PROPERTY_MATCH` 返回正确实例 ID。
- [ ] 已校准数值属性可直接从快照静态命中；属性表未知的实例才进入运行时探针候选。
- [ ] 按匿名信号名查询可列实例并聚合共同 owner 的候选编组；界面明确说明“候选不等于已确认玩家自制物品”。
- [ ] 再次读取相同空属性表时不会误超时；不操作官方面板时仍会超时而不是读取旧文件。

## D. 空间功能

- [ ] 编组贴地“预览”只打印计划，不调用 `Element:SetPosition`。
- [ ] “执行”代码在匿名测试地图只统一修改成员 Z。
- [ ] 贴地后所有成员保持 X/Y、旋转、缩放和相对结构。
- [ ] 错误地板 ID、射线先命中障碍物、成员不存在时安全中止。
- [ ] 斜面/旋转/凹形对象未验证前不标记为通用通过。

## E. 隐私与恢复

- [ ] 公开发布/公共导出脚本返回 `PRIVATE_DISTRIBUTION_ONLY` 且不创建目标目录。
- [ ] VSIX 检查不含 LayerData、`.yuanmeng-inspector`、真实导出、日志、绝对地图路径或官方二进制。
- [ ] 损坏/半写入的新场景文件不会覆盖上一份有效快照。
- [ ] Manual/Auto/Raw head 独立，Auto 不覆盖首选 Manual。
- [ ] 关闭并重开 VS Code 后绑定和首选快照恢复。
- [ ] 匿名诊断包不含真实实例/UI ID、信号名、工程路径、raw 或日志原文。

## F. 安全重绑

- [ ] 删除并重建一个匿名测试元件后，重绑预览只比较同 binding/role/adapter 快照。
- [ ] 多候选、重复 ID、many-to-one 或证据不足时不生成 Lua 补丁。
- [ ] 唯一候选仍先打开预览；变更场景/台账/Lua 任一项后旧预览拒绝应用。
- [ ] 确认补丁后生成备份，“立即撤销”能恢复原 Lua。

## G. AI 玩法测试

- [ ] 未确认草案/静态门错误/Lua、UI、台账或场景指纹变化时，模拟必须阻断。
- [ ] 1/2/4/8 人均有独立结果；任一多人调度失败覆盖单人通过。
- [ ] 同帧事件、重复投递、广播/单播、中途加入/退出/重连、旧计时器、客户端越权与跨玩家污染均有失败用例。
- [ ] NPC 可达、物理接触、镜头效果和真实网络顺序仍列为 `OFFICIAL_EDITOR_MULTI_REQUIRED`。

## H. 尚未验收则必须保留的标记

- [ ] 只有已校准路径中的数值属性和信号名称可记为 observed；非数值属性、资源、碰撞/物理/抓取/边界仍为 candidate/unknown。
- [ ] 超大真实地图性能未测时标记 `PERFORMANCE_GATE_UNVERIFIED`。
- [ ] 多人位置权威未测时不标记 `OFFICIAL_EDITOR_MULTI`。
- [ ] 尚未落盘的编辑器内实时变化和当前鼠标选择明确标记“不支持”；MCP 明确不在本版。
